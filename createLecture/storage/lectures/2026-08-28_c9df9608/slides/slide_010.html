전통적 프로그래밍 vs 머신러닝 vs 딥러닝

전통적 프로그래밍 / 머신러닝

  • 전통: Data + Rules → Output (사람이 규칙 작성)
  • 머신러닝: Data + Output → Model (규칙을 학습)
  • 머신러닝: 사람이 특징(Feature)을 직접 설계

딥러닝

  • 특징 추출과 판단을 동시에 학습 (End-to-End)
  • Representation Learning: 계층적 특징 자동 학습
  • 예: Pixel → Edge → Shape → Object
