Activation Function

4. 인공신경망의 수학적 표현
하나의 인공 뉴런
입력: x1, x2, ..., xn
가중치: w1, w2, ..., wn
Bias: b
입력의 가중합
z = w1*x1 + w2*x2 + ... + wn*xn + b
활성화 함수 적용
y = f(z)
벡터를 이용한 표현
z = w^T*x + b
y = f(w^T*x + b)
하나의 Layer
여러 개의 뉴런을 동시에 계산
z = W*x + b
h = f(z)
W: Weight Matrix
x: Input Vector
b: Bias Vector
h: Layer의 Output
다층 신경망
1번째 Hidden Layer
h1 = f(W1*x + b1)
2번째 Hidden Layer
h2 = f(W2*h1 + b2)
Output Layer
y_hat = g(W3*h2 + b3)
전체 신경망의 표현
y_hat = F(x; theta)
x: Input
y_hat: Prediction
theta: 모든 Weight와 Bias
Loss Function
실제값 y와 예측값 y_hat의 차이를 측정
Loss = L(y, y_hat)
Regression → MSE
Classification → Cross Entropy
딥러닝 학습
Loss가 작아지는 방향으로 Weight와 Bias를 수정
Gradient Descent 사용
Backpropagation을 통해 각 Weight의 Gradient 계산
Weight Update
w_new = w_old - learning_rate * gradient
딥러닝 학습의 전체 흐름
Input → Forward Propagation → Prediction → Loss 계산 → Backpropagation → Weight Update

핵심 정리:
Neural Network = Weighted Sum + Activation Function
Deep Learning = Neural Network + Data + Loss + Optimization
