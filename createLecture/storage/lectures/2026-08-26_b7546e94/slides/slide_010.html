전통적 프로그래밍 vs 머신러닝 vs 딥러닝

전통적 프로그래밍 / 머신러닝

  • 전통: Data + Rules → Output (규칙을 사람이 작성)
  • 머신러닝: Data + Output → Model (데이터로 규칙 학습)
  • 머신러닝: 사람이 특징(Feature)을 직접 설계

딥러닝

  • 특징 추출과 판단을 동시에 학습 (Representation Learning)
  • 계층적 특징 학습: Pixel → Edge → Shape → Object
  • 여러 Hidden Layer = 'Deep'의 의미
