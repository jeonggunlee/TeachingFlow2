전통적 프로그래밍 vs 머신러닝 vs 딥러닝

전통적 방법

  • 프로그래밍: Data + Rules → Output
  • 머신러닝: Data + Output → Model (규칙 자동 학습)
  • 전통 ML: 사람이 직접 특징(Feature)을 설계
  • 분류·회귀 등 단순 과제에 효과적

딥러닝

  • 특징 추출과 판단을 동시에 학습 (Representation Learning)
  • 여러 Hidden Layer → 계층적 특징 학습
  • 예: Pixel → Edge → Shape → Object
  • 대규모 데이터·연산 환경에서 압도적 성능
