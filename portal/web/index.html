주요 기능

📝
강의 제작
  • PPT 업로드 또는 프롬프트만으로 슬라이드 자동 생성
  • AI Vision 기반 슬라이드 스크립트 자동 작성
  • TTS 음성 합성 + 어절 단위 자막 타이밍
  • 마우스 드래그로 강조 영역 지정 · 스크립트 편집
  • CQI 피드백(텍스트) 또는 학습 분석 보고서 JSON 업로드로 스크립트 자동 개선
  • 최근 사용한 프롬프트 재사용, 학습 분석 결과로 슬라이드까지 진화(CQI)
▶
강의 운영
  • 제작 즉시 서비스 (파일시스템 직접 공유, 업로드 불필요)
  • 슬라이드 동기 TTS 재생 · 이어보기 · 강조 효과
  • 슬라이드별 난이도 평가 (쉬움 / 보통 / 어려움)
  • 실시간 채팅 질문 · 한국어 키워드 자동 추출
  • 수강 진도율 자동·안전 저장 (sendBeacon)
📊
학습 분석
  • 수강 데이터 자동 집계 (난이도 · 키워드 · 질문)
  • AI가 슬라이드별 혼란도 지수 산출
  • 핵심 미이해 개념 자동 추출
  • 슬라이드별 개선 지침(권장 조치) 생성
  • CQI 보고서 JSON 다운로드 → 강의 제작에 곧바로 적용

지속적 강의 품질 개선 (CQI)

수강생의 학습 반응 데이터를 AI가 분석해 강의 품질을 지속적으로 개선합니다.
어려운 슬라이드에는 추가 설명을, 혼란이 많은 개념에는 예시를 자동으로 보강합니다.

4
