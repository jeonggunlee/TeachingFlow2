사이클의 시작점,
과목·주차 관리 허브

교수자는 여기서 과목을 등록하고 주차별 강의를 추가합니다. 각 서비스로의 이동은 모두 포털을 거치며, 서비스 직접 링크 대신 흐름 다이어그램이 전체 사이클을 안내합니다.

coursesweekly_lectures
상태 감지 course + week

GET /api/status-week 로 각 서비스를 프로브해 제작·분석 진행 상태를 lecture_id가 아닌 주차 단위로 자동 판정합니다.

오케스트레이션
  • /api/proxy/analyze-week — 주차별 분석 트리거
  • timeout 5s · 서비스 중단 시 graceful fallback
  • 모든 서비스에 "← 포털" 복귀 버튼 (from 파라미터)

포트 8000Claude VisionEdge TTS

PPT 한 장이
말하는 강의가 되기까지

업로드한 PPT를 LibreOffice가 PNG로 변환하면, Claude Vision이 슬라이드별 스크립트와 강조 좌표를 뽑고, Edge TTS가 구간별 MP3와 어절 타이밍을 생성합니다.

CQI 모드

이전 수강생 피드백 텍스트를 붙여넣으면 Claude API가 해당 슬라이드 스크립트를 자동 보강합니다 — 사이클이 닫히는 지점.

제작 파이프라인from 파라미터 필수
1 · 업로드PPT → LibreOffice → PNG
2 · 분석Claude Vision → 스크립트 + 좌표
3 · 편집스크립트 검토 · 강조영역 드래그
4 · 합성Edge TTS → MP3 + .words.json
5 · 산출storage/lectures/{id}/
포털에서만 진입 · 직접 접속 시 리디렉션
